# Logo DEF Engenharia

Versão escolhida em 13/11/2026: opção 1, "Três barras". O E é formado por três barras, que representam as três fases de um sistema trifásico e as três iniciais do nome.

## Qual arquivo usar

| Situação | Arquivo |
| --- | --- |
| Fundo branco ou claro (propostas, laudos, site) | `def-engenharia-principal` |
| Fundo azul-noite ou escuro | `def-engenharia-negativo` |
| Carimbo de prancha e impressão em preto | `def-engenharia-uma-cor` |
| Sobre foto ou cor forte | `def-engenharia-branco` |
| Cabeçalho de site, rodapé e espaços baixos e largos | `def-engenharia-horizontal` (e as versões negativo e uma cor) |
| Foto de perfil, ícone de aplicativo e favicon | `def-engenharia-simbolo` |

Use os arquivos SVG sempre que o programa aceitar, porque eles não perdem qualidade em nenhum tamanho. Esta pasta guarda só os PNG que o sistema e o site usam. O pacote completo, com todas as versões em PNG de fundo transparente para Word, WhatsApp e redes sociais, foi entregue à parte no arquivo `def-engenharia-logo.zip`. No AutoCAD, anexe o PNG de uma cor como imagem. Uma versão em DXF para o carimbo de prancha ainda não foi gerada.

## Cores

| Cor | Código | Uso |
| --- | --- | --- |
| Azul-noite | `#0F2A43` | Letras e fundos escuros |
| Âmbar | `#F5A623` | As três barras e destaques |
| Grafite | `#1F2933` | Texto e versão de uma cor |
| Cinza-claro | `#F2F4F7` | Fundos |

## Letra

A palavra ENGENHARIA usa a Manrope, que é gratuita no Google Fonts. Use a mesma letra em títulos de propostas, laudos e no site. No logo o texto já está convertido em curvas, então não é preciso instalar a fonte para abrir os arquivos.

## Cuidados

- Deixe em volta do logo uma margem livre igual à altura de duas barras do E.
- Não use a versão principal com menos de 25 mm ou 100 px de largura. Abaixo disso, use o símbolo.
- Não estique, não incline e não troque as cores.
- Sobre fundo âmbar ou colorido, use a versão branca ou a de uma cor.
